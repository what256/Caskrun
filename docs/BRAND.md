# Brand review

Reviewed 2026-09-23. This is a working identity for the local prototype, not a trademark clearance opinion.

## Name

**Caskrun is the current working name.** An exact-name web and GitHub repository search on 2026-09-23 found no obvious existing software product or business using this spelling. An unrelated [game character](https://www.ffxivmb.com/Items/Excalibur/2734) uses it. This search does not establish that the name is legally clear; check relevant trademark registers and similar spellings before public release.

**Nuvren was rejected.** An existing [web-development studio](https://nuvren.com/about/) uses that exact name.

**Ruvo is not a clean fallback.** [Ruvo](https://ruvo.app/) already names a software project-management service, and [another Ruvo](https://play.google.com/store/apps/details?id=com.ruvotechnology.ruvo) is a published app. A new name needs its own search across product sites, app stores, domains, and relevant trademark registers before release. Search results alone cannot provide trademark clearance.

### Names considered

These are **provisional candidates**, ranked after exact-name web searches on 2026-09-23. Queries included each quoted name alone and with `app`, `software`, `company`, `GitHub`, and `trademark`. None returned an obvious *current software product or business using the exact name* in those searches. The linked examples show other exact-name uses that did appear; they are not claims of exclusivity.

| Rank | Name | Why it fits | Exact-name use surfaced |
| --- | --- | --- | --- |
| **1** | **Caskrun** (`CASK-run`) | Seven letters, easy to say, and directly suggests running programs inside Wine bottles. Best public-name candidate. | A [game character named Thea Caskrun](https://www.ffxivmb.com/Items/Excalibur/2734). |
| 2 | **Runvial** (`RUN-vial`) | Seven letters and functional; “vial” hints at an isolated container. | A [role-playing character named Runvial](https://www.dndbeyond.com/forums/dungeons-dragons-discussion/play-by-post/94385-the-rise-of-tiamat?page=40). |
| 3 | **Xeravo** (`zeh-RAH-vo`) | Six letters, brandable and less tied to Wine if the app expands later. Its initial X makes pronunciation less obvious. | A [personal blog username](https://www.tumgik.com/xeravo). |

Before choosing any candidate for release, repeat the search in the distribution markets, check similar spellings and pronunciations, relevant trademark databases, app stores, repository/package registries, and domain availability. A web search can miss unindexed or newly filed marks; this is not legal clearance.

## Symbol

- Current asset: [`../assets/caskrun-icon.png`](../assets/caskrun-icon.png), an original generated PNG with transparent outside corners. It adapts the earlier Caskrun symbol the user preferred. The repository README records its image-generation origin and edit. No CrossOver icon or asset is used here.
- The charcoal tile and white open-container arrow keep their contrast in light and dark mode. The build script creates a macOS `.icns` from this master.
- The logo appears only as the app icon; the window sidebar uses a text title, per the user's preference.
- Test legibility at 16, 32, 64, and 128 pixels and compare against existing software icons before public release.
- This review did not include a similarity search against existing logos. Image generation by itself does not establish that a symbol is unique.

## Release checkpoint

Check Caskrun in the intended distribution markets, including similar names, trademark databases, app stores, and domain availability. Complete the icon and publish only after that check and the runtime licensing review.
